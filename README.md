# Digital Time Machine

> Type any year. Travel through the history of the Internet.

Digital Time Machine is a web application that shows you how the internet evolved overtime and some of the main accomplishments in each era.
---

# Features

## Time Travel

- Enter a year and instantly transform the website.
- Animated loading screen before each transition.
- Different browser titles and address bars for every era.
- Dynamic page rendering without reloading.

# Browser Simulation

Each year changes the browser experience by updating:

- Browser title
- Address bar
- Status bar
- Background colors
- Typography
- Theme
